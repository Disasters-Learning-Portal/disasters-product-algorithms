# =============================================================================
# Canonical DEV-LOCAL conda dep list
# =============================================================================
# Single source of truth for the conda packages needed to develop / lint /
# test this repo OUTSIDE the hub image (e.g. on a laptop or in CI).
#
# Used by:
#   - .github/workflows/lint.yml (the cli-smoke job reads this file)
#   - The "How to install for dev" instructions in pyproject.toml and README
#
# Format: one conda package spec per non-comment line, exactly as it would
# appear to `mamba install -c conda-forge` (e.g. "gdal" or "rasterio>=1.3").
# Lines starting with # are ignored. Blank lines are ignored.
#
# Adding a new dep:
#   - Pip-installable (manylinux wheel) → prefer pyproject.toml [project.dependencies].
#   - Conda-only / native lib / GDAL plugin → add a line here.
#   - If the hub image also needs the new conda dep ON TOP of Pangeo base,
#     ALSO add it to hub-conda-deps.txt (which is auto-synced to the image
#     repo by .github/workflows/sync-conda-deps.yml). hub-conda-deps.txt
#     covers deps that aren't already in Pangeo base — most things below
#     ARE in Pangeo base, hence the difference between the two files.
# =============================================================================

# --- Geospatial stack (GDAL must come from conda, not pip — see hard rule #6) ---
gdal
# JPEG2000 (.jp2) driver for Sentinel-2 bands. conda-forge GDAL 3.9+ ships it as a
# separate plugin a bare `gdal` install doesn't pull in; without it every S2 band
# read fails "gdal_JP2OpenJPEG.so is not available" and process_sentinel2 yields
# zero products. UNPINNED (ABI-locked to libgdal-core; let conda match GDAL).
# Mirrors image/environment.yml + dps/environment.yml so local dev / CI / DPS agree.
libgdal-jp2openjpeg
rasterio
rio-cogeo
geopandas
pyproj

# STAC client for the Sentinel-2 STAC pipeline
# (sentinel2/sentinel2_stac_functions.py imports pystac_client at module
# level). Also in pyproject [project.dependencies] for the pip path.
pystac-client

# Rayleigh scattering correction for Sentinel-2 L1C
# (sentinel2/sentinel2_stac_functions.get_rayleigh_correction).
# The module RAISES rather than silently skipping the correction when
# this is missing, so it is a hard dep of the L1C path, not optional.
# NOTE: the package alone is not enough at run time -- Rayleigh() also
# needs RSR + LUT data files, which it will try to DOWNLOAD on first
# use. See image/Dockerfile and dps/Dockerfile for the offline
# provisioning, and tools/pyspectral_selfcheck.py for the gate.
pyspectral

# --- Numerical / image processing ---
numpy
scipy
pillow
lxml

# any env built from this file. matplotlib-base (not matplotlib) to skip the
# Qt/PyQt GUI stack, matching dps/environment.yml. ---
matplotlib-base
seaborn
